В. Ключавыя словы для "Updates" (Кароткія паведамленні)
Калі паведамленне карацей за 50 сімвалаў і ўтрымлівае гэта — гэта UPDATE:
code
Regex
/^(?:поки\s+)?стоп\s*$/i
/^(?:вже\s+)?не\s+актуально\s*$/i
/^група (?:наразі\s+)?зібрана\s*$/i
/^набір (?:призупинено|закрито)\s\*$/i
/актуально є \d+ місце/i 2. Інструкцыя па класіфікацыі (Для AI і логікі)
Каб паведамленне лічылася карысным, яно павінна адпавядаць аднаму з наступных крытэрыяў:
Катэгорыя: FULL_VACANCY (Поўная вакансія)
Што павінна быць (мінімум 3 пункты):
Лакацыя: Назва горада (напр. м. Сєдльце, Warszawa, Poznań).
Аплата: Стаўка ў лічбах + валюта (напр. 25.36 зл/год, 5200 брутто).
Сутнасць працы: Назва пасады або працэсу (напр. пакування м’яса, оператор машин, збірка велосипедів).
Спасылка на дакумент: Наяўнасць Google Docs спасылкі (вельмі часта ў Apolo, FWS).
Жыллё: Інфармацыя пра кошт або наяўнасць хостэла.
Катэгорыя: RECRUITER_INFO (Карысная інфармацыя)
Гэта паведамленні, якія не з'яўляюцца вакансіямі, але важныя для працы.
Прыкметы:
Юрыдычныя змены: Інфармацыя пра статус UKR, PESEL, змены ў законах.
Графік працы офіса: Калі офіс зачынены на святы (напр. 06.04 офіси не працюють).
Патрабаванні да дакументаў: Напрыклад, папярэджанне пра арыгіналы дакументаў або новыя правілы санепіду.
Лагістыка: Інфармацыя пра кропкі збору, аўтобусы, медогляды.
Катэгорыя: UPDATE (Абнаўленне)
Прыкметы:
Змена колькасці месцаў (напр. потрібно ще 7 людей).
Змена даты прыезду (напр. приїзд з понеділка 13.04).
Змена стаўкі (напр. міняємо ставку 30-32).
Закрыццё набору (напр. STOP, група зібрана).
